# Literature dissection 

## General Information

### Title
Literature Dissection: situating the NCOS prescribed burn study within existing research

### Description
This repository contains the materials for the Literature Dissection assignment for ENVS-193DS/DD (Spring 2026) at UC Santa Barbara. The assignment connects prior research and site documentation to our group final project, which evaluates the effects of the 2023 prescribed burn on native grasses versus non-native vegetation in the North Campus Open Space (NCOS) Mesa grasslands.
